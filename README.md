# ELSHAZLY MOTORS — الشاذلي موتورز

موقع تعريفي (Front-End فقط) لمعرض سيارات فاخرة، بستايل داكن سينمائي مستوحى من مرجع إنستجرام
(موقع AUREL من Batikha Studio): خلفية سوداء، لمسات حمراء، طباعة عملاقة، بطاقات مواصفات عائمة،
وتفاعلات مبنية على السكرول وترانزيشنز سينمائية.

## التشغيل

```bash
npm install
npm run dev      # تطوير: http://localhost:5173
npm run build    # بناء الإنتاج في dist/
npm run preview  # معاينة البناء: http://localhost:4173
```

## التقنيات

- **React + Vite** — فرونت إند فقط، من غير أي باك إند
- **Tailwind CSS v4** — الستايل والثيم
- **Framer Motion** — ترانزيشنز العناصر، السلايدر، المودال، القوائم
- **GSAP + ScrollTrigger** — الجاليري الأفقي المثبّت (Pin + Scrub)
- **Lenis** — سكرول ناعم متزامن مع GSAP
- **Lucide** — الأيقونات

## أقسام الموقع

| القسم | اللي فيه |
|---|---|
| Preloader | عدّاد ٠–١٠٠٪ وستارة بتترفع |
| Hero | زوم سينمائي بطيء (Dolly-in) على البوجاتي + بارالاكس + بطاقات مواصفات عائمة (1600HP / 2.4s / 440) |
| Marquee | شريط ماركات متحرك لا نهائي |
| نجم الأسبوع | سلايدر ٤ عربيات بترانزيشن منزلق + عدّادات أرقام + تنقّل تلقائي (بيوقف وهو الموتور داير) |
| دوّر الموتور | زرار تشغيل بيولّد صوت موتور لايف بـ Web Audio (من غير ملفات صوت) + عدّاد RPM: مارش ← سلانسيه ← دوس بنزين لحد الردلاين، وموجود كمان في نافذة تفاصيل كل عربية |
| عدّاد سرعة السكرول | HUD ثابت بيقيس سرعة سكرولك ويعرضها كم/ساعة بإبرة وريدلاين |
| صور العربيات | صور كاملة بخلفياتها الطبيعية في كل الأقسام (ملفات القصّ الشفافة محفوظة في `public/cars/cut/` لو حبيت ترجعلها) |
| وضع السبورت | زرار SPORT في النافبار بيحوّل الموقع كله لمود رياضي: أحمر مشتعل، سواد مائل للحمرة، توهج نابض، ماركي أسرع بمرتين، وصوت عادم متولّد (دوسة مزدوجة) مع فلاش أحمر واهتزاز خفيف — والاختيار بيتحفظ. والباكدج الكاملة: صور العربيات بتهتز زي موتور داير على السلانسيه، العناوين اللاتينية بتميل ميل رياضي، وكل دوسة زرار ليها صوت كليك ميكانيكي. ومع السكرول السريع: شكمانات افتراضية في ركني الشاشة بتطلع لهب وشرارات وخطوط سرعة بتزيد مع سرعتك |
| بريلودر العدّادات | شاشة تحميل على شكل تابلوه عربية: عدّاد RPM بإبرة بتتحرك مع التحميل، لمبات فحص بتنور وتطفي، وعدّاد كم/ساعة |
| أصوات المواتير | كل عربية بصوت متولّد حسب موتورها الحقيقي: عدد السلندرات بيحدد التردد، التيربو بيصفّر وبيعطس لما تسيب، السوبرتشارجر بيصفر، والكهربا بهمهمة مستقبلية |
| التشكيلة | ١٨ عربية في ٦ فئات — آخرهم GT-R، أودي R8، كورفيت Z06، سوبرا MK4، هيلكات، وتايكان كهربا |
| الجاليري | سكرول أفقي مثبت بالسكرول العمودي (GSAP Pin) |
| التشكيلة | ١٢ عربية + فلترة بالفئة بأنيميشن Layout + نافذة تفاصيل عند الضغط |
| إحنا مين | صورة بارالاكس + ٤ مميزات (فحص، تمويل، ضمان، استبدال) |
| نسخة إنجليزية كاملة | زرار EN في النافبار بيقلب الموقع كله إنجليزي باتجاه LTR — كل النصوص والوصف والشارات والحجز والمقارنة مترجمة، والاختيار بيتحفظ وبيتطبق قبل أول رسم |
| مقارنة وحشين | أي عربيّتين وجهًا لوجه: أشرطة قتال متحركة للقوة والتسارع والسرعة القصوى والسنة والأوفر سعرًا، تاج على كسبان كل جولة، وحكم نهائي بالنقاط مع زرار واتساب للفائز |
| تجربة القيادة | حجز تفاعلي: فرع ← عربية ← يوم ← ساعة، مع شاشة نجاح ورقم مرجعي |
| Footer | CTA + ووردمارك عملاق |

## التخصيص

- **العربيات والأسعار:** `src/data/cars.js` (الاسم، السعر، القوة، التسارع، الصورة، الفئة)
- **الصور:** `public/cars/` — صور Unsplash مجانية، استبدلها بصور المعرض الحقيقية قبل الإطلاق التجاري
- **الألوان:** `src/index.css` في `@theme` (`--color-signal` للأحمر، `--color-void` للخلفية)
- **رقم التواصل:** مكوّنات `Navbar` و`Footer` (حاليًا رقم تجريبي)
- **اسم المعرض:** ابحث عن `ELSHAZLY` في `src/components/` واستبدله

> ملحوظة: الخطوط (Anton + Cairo + Space Grotesk) بتتحمل من Google Fonts، فمحتاجة إنترنت أول مرة.
